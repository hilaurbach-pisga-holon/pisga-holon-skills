  1. מתחילאני עומד בכבוד בזמן ההמנון
  2. מתפתחאני מסביר למה מכבדים סמלים וחוקים
  3. מיומןאני מכבד את החוק גם כשאיש לא רואה
  4. מובילאני מבין את שלטון החוק ופועל לשינוי בדרכים חוקיות

שירות משמעותי (צבאי, לאומי, אזרחי)

  1. מתחילאני עוזר בכיתה ובבית
  2. מתפתחאני מתנדב לתפקיד או למשימה
  3. מיומןאני מתנדב באופן קבוע בקהילה
  4. מובילאני מתכנן ומכין את עצמי לשירות משמעותי

  1. מתחילאני מצביע בבחירות בכיתה

  3. מיומןאני מעורב במועצת התלמידים או בשיח ציבורי
  4. מובילאני מוביל יוזמה דמוקרטית ומשפיע במוסדות ייצוגיים
