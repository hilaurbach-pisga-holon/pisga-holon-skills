אתר להוראת מיומנויות: דפי מיומנות, פעילויות, משימות וחדרי בריחה.

## מבנה

אתר סטטי (HTML, CSS, JavaScript). הקובץ `index.html` הוא דף הפתיחה.

## שש מיומנויות הליבה (8.11.2026)

דף הבית מציג שש מיומנויות ליבה (core-*.html), כל אחת עם 8 צעדים בתוך ארבעת השלבים, ומפת צעדים (steps.html). המסגרת המלאה של 13 המיומנויות עברה ל-all-skills.html. הצעדים הם טיוטה לדיון במפגש המנהלים ב-22.12.2026.

## כל המיומנויות (24.11.2026)

`skills.html`: כל 52 הפריטים שבמפת המיומנויות והערכים, בשלושה שערים (מיומנויות, ערכים, כשירויות משלימות), עם חיפוש. לכל פריט עמוד `item-<מזהה>.html` (למשל `item-s04.html`): הגדרה ומקור, יכולות, ארבע רמות (מתחיל, מתפתח, מיומן, מוביל), איך עוברים, יעד לפי שלב חינוך, קישור למדרג, לפעילויות ולמחשב המסלול.

העמודים נבנים מהנתונים שבתוך `route.html`. אחרי עדכון הנתונים שם מריצים:

```
python3 scripts/gen_all.py .
```

הסקריפט גם מעדכן את התפריט בכל העמודים ואת דף הבית. מיומנויות הליבה של חולון נשארו בדף הבית.

## מחשב המסלול (22.11.2026)
