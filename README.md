# מרכז המיומנויות – הבוגרת והבוגר 2030

קישור לאתר ב-GitHub Pages: https://hilaurbach-pisga-holon.github.io/pisga-holon-skills/

(הגרסה הישנה ב-sites.tab.bot לא מתעדכנת מ-GitHub.)

אתר להוראת מיומנויות: דפי מיומנות, פעילויות, משימות וחדרי בריחה.

## מבנה

אתר סטטי (HTML, CSS, JavaScript). הקובץ `index.html` הוא דף הפתיחה.

## מיומנויות הליבה של חולון

שלוש מיומנויות הליבה שנבחרו בעירייה: התנהלות חברתית (S11), פתרון בעיות (C52), מודעות חברתית (S10). דף הבית מציג אותן, ובעמוד של כל אחת יש פעילות לכל מעבר בין רמות בכל יכולת, ו"מה מחפשים" כדי לדעת שהתלמיד עלה רמה. דפי שש המיומנויות הקודמות (core-*.html) ומפת הצעדים (steps.html) הוסרו.

## כל המיומנויות (24.11.2026)

- `skills.html`: כל 52 הפריטים שבמפת המיומנויות והערכים, בשלושה שערים, עם חיפוש.
- `item-<מזהה>.html` (למשל `item-s11.html`): הגדרה ומקור, יכולות, ארבע רמות (מתחיל, מתפתח, מיומן, מוביל), איך עוברים, יעד לפי שלב חינוך, פעילויות, קישור למדרג ולמחשב המסלול.
- `print-item-<מזהה>.html`: כלי הערכה להדפסה לכל פריט: כרטיס הערכה עצמית לתלמיד וטבלת תצפית למורה.
- לכל יכולת יש לפחות פעילות אחת. הפעילויות החדשות (ACT-253 ואילך) כתובות בקבצים `data/acts_core.py` (מיומנויות הליבה) ו-`data/acts_extra_*.py`, ויש לכל אחת דף למורה להדפסה (`print-ACT-<מספר>.html`).

הכול נבנה מהנתונים שבתוך `route.html` ומקבצי `data/`. אחרי עדכון מריצים:

```
python3 scripts/gen_site.py .
```

הסקריפט בונה מחדש את עמודי הפריטים, כלי ההערכה, הפעילויות החדשות בעמוד הפעילויות ובמחשב המסלול, את דף הבית, התפריט והכותרת התחתונה. אפשר להריץ אותו שוב בבטחה. הוא גם בודק שאין יכולת בלי פעילות.

## מחשב המסלול (22.11.2026)

`route.html`: כל המיומנויות, הערכים והכשירויות המשלימות (52, עם 200 יכולות ורכיבים), לכל יכולת ארבע רמות (מתחיל, מתפתח, מיומן, מוביל), איך עוברים מרמה לרמה, יעד מוצע לפי שלב חינוך, וקישור למדרג ולפעילויות של האתר. קישור ישיר ליכולת: `route.html#S11.1`.

## קיר תוכנית הטיסה (מפגש מנהלים 22.12.2026)

- `wall.html`: הקיר החי למצגת ("מגדל הפיקוח: לוח הנחיתות"), מתעדכן כל 4 שניות.
- `wall-form.html`: הטופס לשולחנות (`?table=3` ממלא את מספר השולחן).
- `wall-qr.html`: כרטיסי ברקוד להדפסה, אחד לכל שולחן (`?n=10`).
- התשובות נשמרות בגיליון גוגל דרך `apps-script/wall-Code.gs`. את כתובת ה-exec מדביקים ב-`wall-config.js`.
