איפה אני באוריינות מידע?

קוראים כל שורה ומסמנים את המשפט שהכי מתאר אותך היום. אין תשובה נכונה: זה עוזר לנו לבחור את הצעד הבא.

איתור מידע

  1. מתחילאני מחפש מידע במקור שנותנים לי
  2. מתפתחאני מנסח מילות חיפוש ומוצא מידע רלוונטי
  3. מיומןאני מגדיר איזה מידע נדרש ובוחר מקורות מתאימים
  4. מובילאני מאתר מידע ביעילות בכמה מנועים וסוגי מקורות

הערכת מידע

  1. מתחילאני אומר אם מידע נראה לי נכון
  2. מתפתחאני משווה בין שני מקורות
  3. מיומןאני מעריך מידע לפי אמינות, עדכניות ורלוונטיות
  4. מובילאני מעריך באופן ביקורתי סוגי מקורות שונים ומכריע ביניהם

ארגון מידע

  1. מתחילאני ממיין מידע לפי כותרות שנתונות לי
  2. מתפתחאני מתעד מידע בטבלה או בכרטיסים
  3. מיומןאני ממזג מידע מכמה מקורות בשיטה שבחרתי
  4. מובילאני בונה מבנה ארגון משלי ומתעד מקורות בעקביות

שימוש במידע

  1. מתחילאני מספר במילים שלי מה מצאתי
  2. מתפתחאני מסכם מידע ומציין מאיפה לקחתי
  3. מיומןאני מעבד מידע מכמה סוגים ומסיק מסקנה
  4. מובילאני בוחן השערות במידע ומשתמש בו באופן חוקי והוגן

הצגת מידע

  1. מתחילאני מציג מידע בציור או בכמה משפטים
  2. מתפתחאני מציג מידע מסודר בדרך אחת
  3. מיומןאני בוחר דרך הצגה שמתאימה למטרה ולקהל
  4. מובילאני מציג מידע בבהירות ובמגוון דרכים כדי להסביר, לשכנע ולהניע
