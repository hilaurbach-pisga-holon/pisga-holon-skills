אוריינות כמותית

  1. מתחילאני מונה, משווה כמויות ומחשב בעזרת המחשה
  2. מתפתחאני מחשב ומעריך תשובה באומדן לפני החישוב
  3. מיומןאני בוחר פעולה ודרך חישוב מתאימות לבעיה מהחיים
  4. מובילאני בונה מודל כמותי למצב מורכב ובודק את סבירות התוצאה

ייצוג מופשט

  1. מתחילאני מזהה חוקיות בסדרה ומתאר אותה במילים
  2. מתפתחאני מבטא חוקיות בייצוג אחד: טבלה, גרף או ביטוי
  3. מיומןאני עובר בין ייצוגים ומסביר את הקשר ביניהם
  4. מובילאני מכליל מהמקרה הפרטי לכלל ומצדיק את ההכללה

חשיבה גאומטרית

  1. מתחילאני מזהה ומשיים צורות סביבי
  2. מתפתחאני מתאר תכונות של צורות ומשווה ביניהן
  3. מיומןאני משתמש בתכונות ובטרנספורמציות כדי לפתור בעיות במרחב
  4. מובילאני מצדיק טענה גאומטרית בהוכחה מנומקת

אוריינות נתונים

  1. מתחילאני ממיין ומונה פריטים ומציג אותם בתרשים פשוט
  2. מתפתחאני אוסף נתונים, מציג אותם וקורא מהם מידע
  3. מיומןאני מפרש נתונים, משווה קבוצות ומסיק מסקנה זהירה
  4. מובילאני בוחן השערה בנתונים ומזהה הטיות ומגבלות
